## 📚 Sobre o Projeto

Este repositório contém um exercício prático realizado como parte das atividades da **Digital Innovation One (DIO)**, com foco na exploração da ferramenta **NotebookLM**.

O objetivo foi compreender como a ferramenta pode ser utilizada para:

- Organizar informações
- Gerar resumos automáticos
- Criar perguntas e respostas baseadas em fontes
- Estruturar conhecimento de forma assistida por IA

---

## 🎯 Objetivos do Exercício

- Explorar os recursos do NotebookLM
- Testar geração de insights com base em documentos
- Documentar aprendizados
- Publicar o resultado no GitHub como parte do desafio da DIO
